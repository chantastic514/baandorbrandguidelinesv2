# Baan d’Or Digital Brand Guidelines V18

Upload the contents of this folder (index.html, assets/, .nojekyll) to the root of the brand guidelines repository. Enable GitHub Pages from the main branch, root directory. The page is standalone and does not use the website CSS or JavaScript. Google Fonts are optional network resources with local system fallbacks. Visual examples are not live booking actions.

All design standards are consolidated inside one main container. Photography is copied from the existing V18 website package. Production website changes and browser testing are outside this package.
